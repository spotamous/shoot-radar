What to watch for here

Each condition gets a 0–100 score. You're alerted when it reaches the threshold you set.

Sea point for swell and tides (advanced)

Swell and tide need an ocean grid point. If a spot shows "no ocean data", set a point a few km offshore. Leave blank to search automatically. Tides are modelled; check BoM tide tables for exact times.

Phone notifications

1Notification keys Done

Creates a key pair. The public half is saved with your settings; the private half goes into a GitHub secret so only your repository can send to your phone.

Copy this private key now. In GitHub open your repository → Settings → Secrets and variables → Actions → New repository secret. Name it VAPID_PRIVATE_KEY and paste the key as the value. It is shown only once.
